# Person and Student — Inheritance

## Problem Statement
```
Create a base class Person with the following attributes:
name
age

Create a derived class Student that inherits from Person and additionally contains:
roll_no
course

Use inheritance to reuse the properties of the Person class.
Use super() to initialize the attributes inherited from the parent class.
```

## Input Format
The input consists of four lines:
First line: Name
Second line: Age
Third line: Roll number
Fourth line: Course

## Output Format
Display:
Name: <name>
Age: <age>
Roll No: <roll_no>
Course: <course>

## Sample Test Case 
Input
Preeti
25
101
Python

Output
Name: Preeti
Age: 25
Roll No: 101
Course: Python
