# Payment System — Abstraction
```
Create an abstract class Payment that contains an abstract method:
pay()

Create three classes that inherit from Payment:
UPI
CreditCard
Cash

Each class must provide its own implementation of the pay() method.

The program should accept the payment type and payment amount and display the corresponding payment message.
Use Python's abc module to implement abstraction.

Input Format
The first line contains the payment type:
UPI
CreditCard
Cash
The second line contains the payment amount.

Output Format
Display:
Payment of <amount> successful using <payment type>
Sample Test Case 1
Input
UPI
2500
Output
Payment of 2500 successful using UPI
```
