# Student Details — Class and Object
```
Create a class Student to store the details of a student.
The class should contain the following attributes:
name
roll_no
marks

Use a constructor __init__() to initialize the attributes.
Create a method display() to display the student details.
```

### Input Format
The input consists of three lines:
First line: Student name
Second line: Roll number
Third line: Marks

### Output Format
Display the student details in the following format:
Name: <name>
Roll No: <roll_no>
Marks: <marks>

```
Sample Test Case 1
Input
Preeti
101
85

Output
Name: Preeti
Roll No: 101
Marks: 85

Sample Test Case 2
Input
Rahul
205
92

Output
Name: Rahul
Roll No: 205
Marks: 92

Sample Test Case 3
Input
Anu
310
76

Output
Name: Anu
Roll No: 310
Marks: 76
```
