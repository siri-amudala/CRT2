# Shape Area — Polymorphism

```
Create three classes:
Circle
Rectangle
Triangle

Each class must contain a method called:
area()

The same method should perform a different calculation depending on the object.
Use the following formulas:
Circle    → π × radius × radius
Rectangle → length × breadth
Triangle  → 0.5 × base × height

Display the area rounded to 2 decimal places.
```

## Input Format
The first line contains the shape name.
For Circle:
Circle
radius

For Rectangle:
Rectangle
length
breadth

For Triangle:
Triangle
base
height

## Output Format
Area: <area>
The area should be displayed with two decimal places.
Sample Test Case 1
Input
Circle
5
Output
Area: 78.54
